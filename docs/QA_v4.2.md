## 离线文件验证

用 Chromium 直接打开构建后的 `file://` HTML，并将浏览器设为离线。通过真实 DOM 按钮交替左右投币六次，可投次数由 50 变为 44；LCD 跟随实际物理收币更新。没有远程 HTTP 请求，也没有浏览器运行错误。点击吉祥物不扣币，能播放内嵌语音；八段音频均可解码。

`npm run build` 和 `npm run pages` 均已通过。以上为发布前本地验收，线上发布状态以 GitHub Pages 部署记录为准。

## 画面复核

逐张查看手机、小屏、大手机、横屏、平板、桌面的实际渲染，以及启动页、吉祥物字幕、币仓、补给、收币和设置状态。正常游玩没有“推进 / 收回”浮层；字幕和联动状态进入后屏。主操作热区至少 44px，彼此独立。最后修正了手机设置舱第五个按钮越界，并将六种尺寸的设置边界纳入回归。

关键文字与按钮源配色通过 4.5:1 对比度检查；3D 光照后的最终像素不作为完整无障碍认证。

## 尚未声称完成的验证

- 自动化播放与解码检查不等于真人听审；合成普通话不是官方角色声线。
- 软件渲染不能代表目标手机 GPU 帧率；没有保证所有手机 60fps。
- 自动八关流程不是真人无辅助通关验证；自然投币仍会出现未达标样本，完整长期平衡需要继续试玩。
