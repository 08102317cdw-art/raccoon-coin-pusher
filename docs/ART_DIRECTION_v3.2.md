# v3.2 美术与界面改版

## 对照依据

- 用户提供的原版游戏实机与商店截图。
- [RACCOIN Steam 官方商店截图](https://store.steampowered.com/app/3784030/RACCOIN_Coin_Pusher_Roguelike/)。仅用于分析构图和视觉层级；不打包原作截图、模型、纹理或音频。
- 色彩继续使用大肥鱼系列的蓝白、海洋青与少量黄铜，不照搬原作配色或像素素材。

## 差距与本次修改

| 维度 | 改版前 | v3.2 |
| --- | --- | --- |
| 构图 | 远景整台机身、右侧应用侧栏 | 近景推币台，上方计分、左侧轮盘、右侧币舱、下方操作台组成一台街机 |
| 机身图案 | 大块浅蓝材质和少量边线 | 海潮嵌纹、鲸鱼徽章、罗盘刻度、双层镶边、螺钉、蚀刻与织纹台毡 |
| 空间氛围 | 平面海边背景、过亮泛光 | 原创夜间游乐厅背景、暖灯、受控泛光、蓝白珐琅和偏哑光金属 |
| 金币 | 亮面金属、细节易过曝 | 降低镜面与凹凸强度，增加压印文字、齿圈和细密同心刻纹 |
| 能量转盘 | 六个文字标签同时晃动，直接显示答案 | 六扇区真转盘、固定指针、独立旋转盘、逐渐减速、按真实奖励准确停靠、连续开奖排队 |
| 抽奖层级 | 转轮与能量弹层争抢画面 | 幸运门老虎机缩为辅助模块，能量轮盘为独立侧边机构 |
| 商店 | 大角色立绘、分散卡片、透明固定底栏挡住购买 | 统一机台屏幕边框、图案化三选一、紧凑商品卡、实色操作底栏 |
| 币仓 | 明亮选中背景与新配色冲突 | 深色选中卡与高对比文字，保持大代币预览与联动图鉴 |
| 响应式 | 两套视觉与重挂载逻辑 | 单一响应式机台，共用真实画布与控件；手机轮盘可展开、不遮挡底层误投 |

## 不改变的规则

- 8 关、三投币槽、摇台、兑币、特殊币与存档键保持。
- 轮盘奖励权重仍由 `stage-rewards.js` 的 `LOTTERY` 决定。六扇区只是奖励分类，不代表等概率，界面明确说明。
- 奖励仍按原有流程入账；转盘只负责有序揭晓，不再次发奖。
- 新增纹样与背板没有物理碰撞体，不改变币的运动或积分规则。

## 实现与测试

- `src/mobile-cabinet.js`：统一机台、控件重排、设置、轮盘焦点与输入隔离。
- `src/mobile-cabinet.css`：机台与附属屏幕的响应式视觉系统。
- `src/prize-wheel.js` / `wheel-math.js`：真实扇区、确定性停靠、队列与减少动态效果支持。
- `src/cabinet-finish.js`：原创机身纹样、鲸鱼徽章与制造细节。
- `src/cabinet-scene.js`：集中构建机台、投币槽、灯带与粒子；保持原初始化顺序，与运行规则分离。
- `src/arcade-room.js`：嵌入式原创 AI 辅助绘制背景；在线、离线构建均不额外请求图片。
- `npm test`：规则及转盘几何测试。
- `npm run build && node tests/arcade-redesign.cjs`：桌面 / 手机 / 小屏 / 横屏 / 平板、币仓、商店、轮盘、设置、跨断点、存档回归。

这是在现有 Three.js 游戏上的原创美术重构，不是原版素材移植，也不声称已经逐像素复现原作的材质、动画或所有画面效果。
