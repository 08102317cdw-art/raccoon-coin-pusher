# v4.3 纵向满幅机台与真实 Live2D

## 呈现范围

竖屏根据游戏画框的纵横比，把机台后屏抬高、实体按键操作台下移；收币口与操作台之间加连续的深蓝金属裙板、侧边与铜色接缝。宽横屏仍使用左侧后屏、右侧推币场，不硬塞纵向长机台。相机继续拟合真实屏幕与实体按钮，独立语义控件保留至少 44px 热区。

币场刚体、碰撞体、重力、入口、推板行程及计分规则未随外观拉伸。前沿收币通道仍敞开，裙板在收币口下方。长竖屏的吉祥物移到平台左侧，不挡硬币或投币键；矮竖屏和桌面仍在左侧机架。

## Live2D，不是整体贴图摆动

采用已有许可的 Q肥鱼 Cubism MOC3 模型，269 个 drawable、247 个参数。没有声称本项目从零绘制分层原画或制作绑定，也不包含可编辑 `.cmo3`。原模型、来源、使用须知及许可在 `models/mascot-live2d/`。

- 原生眼睑参数眨眼，约 4.1 秒一周期。
- 视线跟随指针，头部有限幅转向；呼吸与模型原有物理驱动。
- 点击触摸反应，不消耗普通投币次数。
- 现有通用合成普通话音轨通过 Web Audio 分析音量驱动口型；不是语音识别或逐音素口型。关闭声音即关闭口型，声音不克隆真人。
- 减少动态效果时固定头角度、呼吸，跳过大幅触摸动作，保留眨眼与必要口型。
- 纹理最长边 1024px；独立 256×320 透明画布，最多 24 次/秒刷新。没有固定 60fps 的设备承诺。
- 运行库/模型加载失败时回退静态立绘，并在交互目标标题和诊断中明确说明；不阻止进入游戏。

`src/live2d-mascot.js` 驱动真实 Cubism 参数；为了避免 Framework/Core 版本差异，使用官方 5.2 Redistributable Core 与固定 PixiJS 6.5.10、pixi-live2d-display 0.4.0，版本不随 CDN 浮动。资源经过本地 gzip→Blob 解包，不访问模型服务器，不开启摄像头。

`tools/pack-live2d.py` 可从检查入库的模型资源重新打包，无需网络。普通构建由 `bundle-live2d.cjs` 固定依赖生成 ESM 包。`build.cjs` 内嵌 Core、依赖、模型和完整许可文本，离线 HTML 可独立打开；`prepare-pages.cjs` 生成在线入口。在线 Three.js / Rapier 的原有 CDN 路径未改。

## 验证与边界

- `npm test`：原有规则、币种、入口、奖励、轮盘、档案及语音单元测试。
- `npm run test:cabinet`：真实后屏数据、实体按钮投影、特殊币嘴落点、语音静音持久化、六种尺寸与设置舱。
- `npm run test:mobile`：手机竖横屏、投币额度、代币舱、商店、轮盘、存档与输入隔离。
- `npm run test:rig`：实际 `file://` 离线加载；真实 MOC3 网格/参数数目；变形顶点指纹；变形前的原生眼睑/头角/口型参数；语音音量变化、静音闭口；触摸不扣币；六尺寸中吉祥物不遮按钮；长竖屏上下边距；减少动态效果；Core 缺失回退。

Cubism 会在每帧变形后恢复 motion 基线，因此诊断取样在 `beforeModelUpdate`、参数设置之后；不能把恢复后的参数误当最终渲染参数。网格指纹则取实际变形顶点。

浏览器自动化使用软件 WebGL，不替代真实手机的持续帧率、散热、耗电和浏览器兼容性测试。口型为音量驱动，不等于音素同步。没有观看用户链接视频的全部内容；仅依据视频页面公开介绍理解分层/绑定/运行时流程，实际接入的是另一份公开许可模型。

本轮为 v4.3 预览，尚未覆盖已上线的 v4.2。后续发布前应生成 Pages 入口、复核文件完整性，再明确更新上线状态。

已逐张人工检查 390×844、360×640、430×932、844×390、1024×768、1440×900 的机台截图，以及手机/桌面设置舱和吉祥物近景。长竖屏实际可见吉祥物轮廓与操作键不重叠。自动几何检查以不透明角色轮廓为准，排除原模型画布的透明留边。

390×844 下，LCD 有效区域距画框顶边约 37.7px，按键热区底部距画框底部约 28.8px；430×932 下约为 43.8px / 35.3px。外框与显示区边界不同，截图中的屏幕金属边框更靠上。

直接以 `file://` 打开成品，模型与游戏均就绪，未产生远程请求或页面运行错误。实测眨眼参数 0.0417–1.0；播放语音时口型参数随音量变化，静音归零。移除 Core 的故障场景可进入静态后备，正常运行不受阻断。

测试使用 headless Chromium / 软件 WebGL、DPR 1；未宣称完成实体手机长时间帧率与温度测试。源码包附本轮 JSON 证据与主要截图。
