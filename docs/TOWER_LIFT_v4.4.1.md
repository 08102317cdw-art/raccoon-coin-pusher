# v4.4.1 机械金币塔

金币塔从原先一次性在空中生成，改为台面底阀解锁、六叶机械阀展开、金币塔旋转上升、落座交给物理、托盘回落与底阀闭合。机台相机与手机可玩面积保持原取景。

## 对照与设计范围

参考[原作发行商截图 9](https://www.playstack.com/_astro/9.w0dO_5aM.jpg)的成塔进度和塔形，并重新查看 Steam 官方 `RACCOIN - Gameplay Trailer 2` 的 22.4–25.4 秒连续画面。官方视频索引来自 [Steam 公开产品接口](https://store.steampowered.com/api/appdetails?appids=3784030&l=english)。公开资料能够确认逐层成塔与进度表达，未完整确定底阀结构、精确旋转角与时长。

本次按用户指定的底部机械升塔方式设计。六叶底阀、锁销、托盘、三枚一层的交错堆叠、1.25 圈旋转和约 4.8–5.3 秒的逻辑演出时长均为本项目调校，不声称为原作内部参数。

## 演出与物理

- 锁销退开，然后展开六叶阀门；叶片完全打开后开始升塔。
- 金币已是实际 Rapier 刚体，在地下底舱等待。演出期间使用运动学刚体按固定物理步推进，能逐渐顶开已有币堆；地下金币不参与入账、漏币或特殊币联动。
- 升到终点后短暂停稳，再把同一批金币切换为动态刚体。清除机构驱动速度，不另生成副本、不施加人为炸散冲量；后续推动与倒塌由物理计算。
- 托盘回落、阀门闭合后恢复投币。演出期间暂停投币、摇台与主动结算，后续轮盘排队等待；打开菜单、币舱、说明或切到后台时随主物理时钟暂停。
- 计分屏显示解锁、开阀、旋升层数、落座与归位；原创合成音效分别对应锁销、电机和落座。减少动态效果时压缩流程，取消全塔旋转。

## 奖励与存档

奖励数量继续按原规则计算：普通塔为 42 枚，高塔及轮盘倍率增加数量，最多 84 枚；不改变奖项权重或台面 420 枚上限。三枚一层重新排布塔形，让相同数量更有高度。不能容纳的数量继续逐枚折为兑币票。

存档升级为版本 7，并兼容版本 2–6。保存已支付金币的真实位置、机构批次与层位、演出进度和是否已经交给物理。升塔中刷新会继续机构动作；交接后刷新不会重复装塔或支付奖励。局内结算会等待升塔完成。

## 文件与验证

- `src/coin-tower-lift.js`：机械结构、固定步动画、物理交接与恢复。
- `src/main.js`：奖励接入、输入与结算协调、存档。
- `src/audio.js`：分阶段合成机械音效。
- `npm run test:tower`：27 项断言，覆盖真实刚体、地下装填、逐段开阀、旋升、暂停、两次刷新、交接、动态推动、高塔、结算与轮盘排队。
- `npm run test:rewards`：25 项奖励守恒与幂等检查，包含满台、部分折票与刷新。
- `npm run test:mobile`：手机、横屏与桌面的投币、币舱、奖励、补给与恢复回归。
- `npm test`：原有规则与物理断言。

`tools/preview-tower.cjs` 可直接触发真实游戏流程并逐帧导出七秒静音演示。运行前构建游戏，设置 `FFMPEG_PATH` 后执行 `node tools/preview-tower.cjs`，结果保存在 `dist/tower-qa/机械金币塔.mp4`，同时生成特写版。预览不随正常构建发布。
