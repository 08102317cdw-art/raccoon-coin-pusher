# v3.3 手机机台改版与规则边界

## 目标

以手机竖屏为主要战场：计分屏、真实推币区与拇指操作台连成一台机器。去掉永久显示的老虎机和幸运门准心；奖励轮是临时机械组件，商店与币仓是同一机壳内的补给舱。

## 已实现

- 390×844 主要布局；360×640、430×932、844×390、1024×768、1440×900 断点回归。
- 手机相机采用更俯视的近景角度；不再为旧老虎机预留画幅。
- 转盘 idle → entering → spinning → revealed → retracting → idle；放绳、过冲回摆、减速停靠、收绳彻底隐藏。普通动画 720 / 2600 / 1450 / 520 毫秒；减少动态效果跳过运动但保留结果阅读时间。
- 连击达到 8 / 16 / 32 / 64 / 128 档位、断连 0.9 秒后开奖，最高 ×5。除已知 8、16 的画面线索与 ×5 上限外，后续门槛和时间窗是本项目调校，不冒充原作内部数值。
- 四扇区一级轮可进入四扇区二级轮；一级提供金币、礼品或进阶，二级提供金币塔或礼品。概率及数量是调校值，扇区面积不代表概率。
- 金币塔最多 12 层 ×7 枚，有真实 Rapier 物理体。台面总数仍受 420 枚上限约束；金币雨有有界队列。
- 未揭晓奖励写入存档；已发奖奖励立即从待发队列排除；二级奖励在一级揭晓时进入队列。旧票券、贝壳、特殊币待发结果仍可恢复。
- 补给舱内部独立滚动，下一关拉杆固定；结算小票可展开；货架购买和返回机台入口完整保留。
- 币仓固定行高，不再因容器压缩而切掉币名；小屏筛选横向滚动，列表竖向滚动。
- 动效粒子和 DOM 飞币均有数量上限；减少动态效果抑制镜头呼吸/震动与高频侧灯变化。

## 未完成，不应对外宣称全量复刻

- 原作十五回合完整目标曲线与各难度规则。
- 六角色、150 代币、完整道具/镀层/挂件体系及全部精确数值。
- 本项目礼品使用既有原创海湾物件，不是原作全部奖品球物件。
- 本项目保留 FEVER、八关目标、票券兑币、贝壳经济和部分原创三选一规则。
- 未做真实低端手机性能基准与真人全流程平衡通关；桌面 Chromium 软件 WebGL 的自动化不能替代这些测试。

## 自动化

`npm test`：规则、代币、投币槽、奖励、四/六扇区停靠几何、连击触发与队列清洗。

`npm run build && npm run pages && npm run test:mobile`：真实离线包启动、六尺寸控件边界与触控尺寸、币仓内部滚动、输入隔离、两级轮队列、自动收绳、未开奖恢复/已开奖不重付、商店购买、下一关、跨断点单画布、进度保存。

可用 `QA_DIR=/data/qa npm run test:mobile` 留下实际浏览器截图供逐张人工目检。
