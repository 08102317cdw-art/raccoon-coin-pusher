# v4.2 · 实体机台与沉浸交互

## 改版边界

不新增货币、掉落脚本或通关捷径。本轮只重做机台呈现、机械结构与互动；保留 v4.1 的双入口物理、真实传力、有限普通投币、独立特殊币库存及八关 / 无尽存档。

## 从浮层转为机台零件

- 移除“推进 / 收回”浮层和重复的周期说明，不让状态读数盖住币堆。联动与连击说明改由后屏显示；收币只保留前沿下方的单行汇总与飞向真实后屏的光点。
- 分数、目标、关卡、余币、贝壳、倍率、连击使用真实后屏的发光 CanvasTexture，直接读取 Run 和 ComboWheel。海湾插画是原创 AI 辅助背景，不是静态分数截图。
- 倍率详情和吉祥物有投影到模型的语义按钮；键盘焦点仍可见。无障碍文本保留在可读 DOM 中。
- 普通三键、兑币与摇台是有插座、黄铜压圈、实体键帽和按压行程的 3D 机台按钮。HTML 只保留透明触控热区，不绘制第二套文字按钮。
- 币舱入口采用金属舱门插画，特殊币夹保留独立的圆形插座，避免把藏币量和普通额度混在一起。

## Blender 机械模型

原创模型：`models/whale-cabinet.blend`，网页模型：`models/whale-cabinet.glb`。

- 左右入口：固定底座、铸造壳体、检修盖、导币口、折边槽、刚性支架、螺钉和状态灯。入口坐标仍为 x=±4.3、y=1.65、z=-4.7；普通币初速度仍为相向 9 单位 / 秒，之后由 Rapier 接管。
- 中央特殊币：双端立柱、轴承导轨、移动滑车、滚轮和短开口送币嘴。没有原先悬空的大托盘，也不再把整个机构压扁来假装工作。
- 滑车沿导轨左右移动，不绕未连接的支点摇晃。模型内 `SpecialCoinOutlet` 和物理 `SPECIAL_OUTLET` 对齐，y=2.45、z=0.6；扩展摆幅时同样检查三轴一致。
- 横屏切换为带底座的侧置操作屏，避免把整台竖机缩成邮票；屏幕仍是场景模型，控制台加宽以保留独立触控热区。
- 前沿：黄铜口沿、两侧导流板、敞开的下落空间和带筋收币底槽，避免用整块装饰面板挡掉落币。
- 固定结构合并为少量按材质划分的网格；GLB 小于 1 MB，随 HTML 内嵌，不需要联网拉模型。模型只是外观，未改变原有台面碰撞体。

重建模型：安装 Blender 5.1 后执行 `blender -b --python tools/build-cabinet.py`。也可以使用 `bpy` Python 模块执行同一个脚本。脚本同时保存 .blend、导出 .glb 并更新网页内嵌资源。运行游戏和普通网页构建不需要 Blender。

## 吉祥物语音

- 点击立牌：表情、轻微身体动作、语音回应，不扣普通币。
- 欢迎、收币、大奖、达成目标、闲置陪伴有原创普通话台词；自动播报有限频，手动回应可优先打断。
- 八段通用合成普通话 MP3 内嵌离线；不是角色官方配音，也没有克隆任何真人或声优。
- 设置中“语音”独立开关，状态保存在本地；背景音乐播放时短暂避让语音。浏览器首次需玩家点击开始以解锁音频。
- 字幕在机台 LCD 中，不再用气泡盖住币堆。禁用动态效果时减少动作，不影响字幕、表情或操作。

## 验证

- `npm test`：玩法、碰撞、奖励、轮盘与日志单元回归。
- `npm run test:mobile` / `test:experience` / `test:rewards`：现有端到端回归。外置 runbox / energy-box 的布局断言改为真实 LCD 与模型热区，不改玩法断言。
- `npm run test:feel`：固定种子、真实物理投完 50 次额度，不修改分数或刚体；仅快进轮盘演出。
- `npm run test:cabinet`：GLB 结构、活动送币口与实际生成点一致、LCD 真实状态、无周期浮层、六种尺寸下独立热区、立牌语音与静音恢复、八段音频解码以及无远程依赖。

自动化检查不等同于真人手感测试；软件渲染也不代表目标手机的 GPU 帧率。尚需在用户实际浏览器上体验音量、触感与长时间运行。

完整回归结果、离线验证和未完成的真人验证见 [v4.2 验证记录](QA_v4.2.md)。
