🎮 **v4.0 实施记录与验收**

起点：v3.3.0，提交 `fe7ed7b`。本轮依次处理视觉与辨识、动效与收币、流派、长期循环；过程中依据用户纠正，优先修复了普通三槽与预设落点的问题。

**投币与原作对照**

普通币只有左右两个侧入口。Q / 左键、E / 右键各投一枚；W / 中键 / 空格及双投按钮同时投两枚。两侧硬币从上层侧口带水平初速度进入，始终为动态刚体，受板面、币堆、摩擦与推板影响，取消 `slide` 插值和预写 `land` 落点。固定普通中央口模型已移除。

特殊币由币仓装夹后，点击操作台币面投放；R 切换、F 投放。它们从当前摆槽位置自然下落到下层，消耗特殊库存而不扣普通额度；普通额度耗尽后的十五秒结算期仍可投放。官方视频与实机报告支持双侧普通币和中央特殊摆槽的区别；资源额度关系主要来自实玩线索，本作采用独立库存。物理速度、摩擦、窗口、收益与成长曲线均为本项目调校。

完整证据、视频时间段和未知项见[原作对照证据](原作对照证据.md)。REA 服务实际可用，但用户未安装原作，未生成原作二进制分析 Evidence；本轮没有复制原作资源。

**视觉、界面与反馈**

- 台面特殊币和币仓使用同一份原创 SVG 图案；按流派共用不同币沿模型与缓存材质，无异步图片加载。
- 手机采用更俯视的构图，缩减背板与托盘的视觉占比；保留同一张实时物理画布，四个快捷槽展示图标与库存。
- 币仓预览更紧凑，装夹有飞入反馈；商店增加奖励 / 货架直达、本流派缺少组件和免费补给提示。
- 台面效果区分生长、捕食、传导、生产、爆破和币塔，携带来源与目标；几何并发上限 28，及时释放临时材质与线段。
- 收币按 160 毫秒窗口聚合，累计收益决定反馈等级；声音分为轻收币、连续入账、大额入账和不同联动。
- 普通轮盘默认时长约 2.26 秒，进阶奖励约 3.19 秒；保留快进和减少动态效果。演出时隔离输入，揭晓时支付，已付项不再进入待发存档。

**三条航路与长期循环**

- 潮汐园丁：种植起手，树更快产币，回流水渠让水滴回到生产循环。
- 湾区饲育员：捕食起手，继承猎物成长币值，食物链改装扩展培育与收割。
- 浪涌技师：充能起手，更强充能与更大爆破范围，浪涌线圈追加传导与充能收割。
- 三档难度改变目标、投币与坏币压力。标准八关仍保留；八关后可保留币堆与构筑进入第九关，继续无尽目标与扩展升级上限。
- 图鉴、六种纪念章、最近十二局战报单独保存。局内继续无尽保持同一局 ID，纪录幂等更新；重新开局仅重置局内状态。

**奖励与存档**

金币雨、礼品在满台时保留待发，持续无法送达的数量按规则折为兑币票；待发队列最多 1000 项，超过容量即时折票。币塔只生成剩余可容纳数量，其余折票。旧版队列恢复截为 100 枚的问题已修复。局内存档升级至 version 6，同时接收 version 2–5；新增船员、难度、构筑和档案独立恢复。

初始化预热清理与正式入账使用相同的高度阈值，避免已经落出场地的预热硬币留到开局再计分。键鼠在按下时立即投币，长按连投仍由原有节奏控制，抬起不重复发射。

**构建与运行**

`npm run build` 使用 Node 跨平台生成单文件离线包 `dist/raccoon-coin-pusher.html`；`build.sh` 转发到同一构建器。`npm run pages` 生成引用源码的在线入口。`npm run preview` 在本机 `127.0.0.1:8787` 预览离线包，刷新即可读取最新构建。
