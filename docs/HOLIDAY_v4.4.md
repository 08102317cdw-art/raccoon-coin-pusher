# v4.4 晴日木筏漂流

本次将夜间游乐厅改成阳光海湾：前景机台站在真实木筏模型上，远景是十二秒循环海景视频。计分屏、实体按钮、币舱、靠港商店与新增主菜单使用同一套卡通配色。

## 场景与参考

参考用户提供的[自动作品机网页](https://q8ph0op03irfh.space.mcode.cn/)与[作者视频](https://www.bilibili.com/video/BV1urnR6xEDF/)的场景化组织方式。已查看视频公开预览和制作流程简介，并核对网页的独立 GLB 加载与材质处理。未复制其模型、贴图、视频或代码，也未将登录受限的视频当成完整观看记录。

采用 Blender 便携版制作分件资产，再导出 GLB 接入网页。新增资产均由本项目脚本原创生成：柚木甲板、浮木、麻绳、条纹阳伞、椰子小桌、救生圈、旅行木箱、钓竿、棕榈岛屿。可编辑工程保留独立物体、材质、预览海面、相机和灯光。

- `models/sunny-drift.blend`：可编辑场景源文件，Blender 4.5 LTS。
- `models/sunny-raft.glb`：运行时木筏，按材质合并为九个网格。
- `models/holiday-islands.glb`：背景摄影棚的海岛资产。
- `tools/build-holiday.py`：重建与导出脚本。
- `src/holiday-film.js`：独立背景摄影棚，包含水面波光、云、帆船和海鸟。
- `tools/render-holiday.cjs`：固定时间步导出 288 帧，经 FFmpeg 编码为 1280×720、24 帧/秒、十二秒循环 MP4；同时提供 WebM。
- `media/sunny-drift.mp4`、`media/sunny-drift.webm`、`media/sunny-drift-poster.webp`：视频与静态回退图。

普通构建无需安装 Blender 或 FFmpeg。视频与木筏以内嵌资产进入离线 HTML，运行时只解码一个静音视频；主菜单与游戏共用。远景无需再次运行海岛网格和水面着色器。关闭动景、系统要求减少动态效果、页面隐藏或视频解码失败时使用同构图静态海景。

仅修改资产时重新生成：

```powershell
& ./.tools/blender-4.5.15-windows-x64/blender.exe --background --factory-startup --threads 2 --python ./tools/build-holiday.py
# 如 FFmpeg 未加入 PATH，先设置 FFMPEG_PATH 为实际 ffmpeg.exe 路径。
node tools/render-holiday.cjs
npm run build
npm run pages
```

便携 Blender 放在被忽略的 `.tools/` 中，不进入仓库。

## 视觉与交互

奶油白 `#fff6dc`、苏打薄荷 `#83c9be`、珊瑚 `#ee9a83`、蜂蜜黄 `#f3cb75`、深青文字 `#244b57`。机台采用浅色搪瓷、奶油包边与低金属度五金；台面保留深色衬底，让金币更容易辨认。

真实计分屏改为奶油纸板、珊瑚标题条、鲸鱼插画、圆角资源卡和靠岸进度条。分数与目标使用深青大字；外框为深青与珊瑚，和机身区分。数据仍来自同一局游戏，原屏幕热区与实体按键坐标保留。

主菜单包括开始或继续、船员与航路、真实收藏手册、玩法、声音与动景设置。游戏设置舱新增返回主菜单入口。返回时释放长按投币并保存，暂停局内时钟与物理；继续时保留原局 ID、额度和币堆。进行中重开必须明确确认，保留收藏档案。支持键盘焦点循环、子页 Escape 返回和静态动景。

## 手机可玩面积

木筏和远景不参与机台相机拟合，也不添加碰撞体。不改变 v4.3 的相机视角、推币台、屏幕、按键尺寸与顶部和底部占用。

改版前投影基线存于 `tests/holiday-footprint.json`。在 390×844、360×640、430×932、844×390、1440×900 五种尺寸中，推币区关键点与屏幕边界对比：关键点最大差值 **0 像素**，计分屏宽度比例 **1.0**。这些是浏览器模拟视口证据，不等于所有实体设备的性能测试。

## 验证

- `npm test`：698 项规则、物理、奖励和语音断言。
- `npm run test:cabinet`：118 项实体机构、真实屏幕、可触控热区与离线依赖断言。
- `npm run test:holiday`：37 项主菜单、视频播放和静态回退、设置、重开确认、存档、离线运行、五尺寸面积对比。
- `npm run test:experience`：267 项体验集成断言；初次船员选择增加进入新主菜单子页的步骤。覆盖真实联动、轮盘、八关、无尽与历史去重。

本轮未更改金币碰撞、两侧普通币入口、摆槽、经济、特殊币规则、关卡数量与连击倍率。真实手机性能仍需设备复核；播放器不能解码时会保留静态海景。
