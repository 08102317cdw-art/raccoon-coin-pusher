# 大肥鱼推币机 · Dafeiyu Coin Pusher

Three.js + Rapier 制作的开源 3D 推币机。**v4 普通币只有左右入口，沿上层真实滑动、碰撞并自然跌落；双侧同投会生成两枚币，不存在普通中槽。特殊币从摆槽落入下层，独立消耗币夹库存。** 八关肉鸽：限量投币 → 目标分 → 结算 → 靠港商店 → 下一关；通关可保留币堆继续无尽。

[🎮 在线试玩](https://08102317cdw-art.github.io/raccoon-coin-pusher/)

这是独立的免费非商业同人游戏，不是 Steam《RACCOIN》的移植，也不是 DeepSeek 官方作品，未获官方背书。未使用 RACCOIN 的美术、音频或代码。

## v4.1 传力、收币与视觉聚焦（当前版本）

这次不扩系统，先修“投币没有推进感、台面没有视觉重点”的基础体验。分析与范围见 [爽感改版记录](docs/GAME_FEEL_v4.1.md)。

- **真实传力**：上层由后排两行改为三行衔接，重新布置下层错列币堆与局部叠层，调整三种接触摩擦和推板节奏；入场预热后清理掉落，不把开局散币当成收益。
- **视觉聚焦**：深色机架与推板、暖金硬币和清晰的出币沿；减少大面积金属泛白，修正大金币过强凹凸造成的噪点，手机角度露出币厚与层次。
- **因果反馈**：推进／收回读数，上层落下的实物碰撞，前沿真实入账才触发的灯带、收币数量与分级震动；镜头不再持续大幅漂移。
- **低帧保护**：固定 60Hz 物理最多补六步，覆盖单帧 100ms；持续慢帧时同步降低画布与后处理分辨率并关闭辉光。不是所有设备都能保证 60fps，低于 10fps 仍会限时保护。
- **不改规则底线**：没有脚本掉币、自动加分、收益返还普通额度；双侧动态刚体、特殊币库存、八关与存档兼容保留。
- **新增回归**：`npm run test:feel` 用固定随机种子自然投完普通额度，检查实际下层转移、真实收益、静置防白赢和慢帧补步；不直接调用 `onWin` 或修改分数。

## v4.0 双入口物理投币、可辨识联动与三条航路（历史版本）

- **联动与收币**：种植生长、捕食吸收、充能电弧、生产与爆破采用不同的空间反馈；收币按 160 毫秒窗口汇总，收益大小决定声音和演出等级。普通轮盘约 2.26 秒，进阶轮保留更长演出，可快进。
- **三位船员**：潮汐园丁、湾区饲育员、浪涌技师具有不同起手、被动、跨关补给与货架偏好；回流水渠、食物链、浪涌线圈实际改变规则。
- **长期循环**：平静 / 标准 / 风暴三档难度，八关后可继续无尽；发现图鉴、六项纪念章与最近十二局战报独立保存，重开不删除，同局无尽不重复计数。
- **奖励守恒**：满台奖励先排队，无法送达时折为兑币票；金币雨保存不再截为 100 枚，币塔部分送达时补偿余量，刷新不重复发奖。
- **本地运行**：`npm ci` 后执行 `npm run build`，打开 `dist/raccoon-coin-pusher.html`；Windows 无需另外安装 shell。`npm run pages` 生成在线入口。

## v3.1.0 摆槽、币槽、礼品、能量转盘与航路三选一（历史版本）

公开玩法对应关系写在本版说明末尾。机台主题、19 种特殊币、坏币、靠港商店和八关循环都还在。

- **摆槽**：特殊币从中间那只一直左右摇的滑槽落下，落点就是它当时的位置。摆到边上，币就偏到那一侧的下层；摆回中间，币落在下层中央。
- **币槽**：这是装填特殊币的夹子，不是台面上的洞。开局 2 格，商店「币槽扩容」最多加到 4 格。点空出来的币面即可装填，再从摆槽射出。
- **礼品**：海贝、小鲸玩偶、宝箱会落在台面上，被硬币推进出币口才发奖（分数、兑币票、贝壳，宝箱还会送一枚特殊币）。每进入下一关会再放一件。
- **能量转盘**：每入账 8 枚硬币转一次。奖项有金币雨、兑币票、贝壳、一件新礼品、一枚特殊币，以及少见的币塔。面板可以收起。
- **航路三选一**：过关后出现 3 张牌，来自芯片、特殊币或被动遗物（潮汐芯、礼品网、票夹、宽摆），带常见 / 少见 / 稀有。可以免费重抽一次。不选就进入下一关，等于放弃。公开资料里的挂件是清完一波坏币后的强制三选一，没有写可以跳过；这里改成每关都给，并且不挡住「进入下一关」。
- **收起面板**：补给站、百宝舱、说明和转盘都有「收起」。收起后变成小标签，机台留在画面里。手机竖屏的标签靠上，免得挡住底部三个投币键。

## v3.0.0 固定投币槽

投币不再自由瞄准。普通币从左右槽滑入，特殊币从中间摆槽落到下层。

- **左槽**（Q、鼠标左键、屏幕「左槽」）：硬币向右滑。**右槽**（E、鼠标右键、「右槽」）向左滑。推板向前时，硬币来不及滑到中间，落在你投入的那一侧；推板收回时，滑到中间再落下。
- **同时按左右槽**：两枚在中间相遇。**中槽**（W、空格、鼠标中键、「中槽」）始终直接落在中间，不受推板方向影响。
- **按住**约半秒会锁定该槽并持续投币，再点一下解除。连续点按比按住更快。手机使用三个大按钮，支持按住。
- **特殊币**装填后从中间摆槽落入下层台面，更容易被推向前沿。19 种特殊币和 3 种坏币仍用原来的联动。
- **兑币票**：每枚入账硬币 +1 票。每关可用票兑换 2 次投币，先 12 票、再 18 票，每次 +8 次。落币结算时也能兑。
- **摇台**：每局 1 次，把台面硬币抖向前沿。商店「松台销」每投入 20 枚自动摇一次，不消耗这次免费机会。推板改装等级越高，摇动越有力。
- **爆破币**：投入时先把全场硬币轰向前沿；落入出币口时仍会炸开周围的币。
- 每枚投币都有粒子、轻微震屏、可用时的短震动，以及连投时逐渐升高的落币音。

这是按公开玩法自行实现的大肥鱼版本，不使用原作的美术、名称或文案。没有移植多角色、镀层、币夹扩容或上百种代币。

## v2.2 特殊代币联动

首批 **19 种特殊代币 + 3 种坏币**。这是参考公开玩法后独立实现、重新平衡的大肥鱼版，不宣称与 RACCOIN 逐项一致。

### 怎么玩

1. 点击 HUD 的「普通金币 ∞ · 选择」打开币仓，选择下一种投币；桌面可按 **Q** 轮换有库存的币。
2. 特殊币替换普通投币，**仍消耗一次关卡投币额度**，另消耗一枚币仓库存；用完自动回到普通币。新局附带首批组合试用币。
3. 联动由真实台面代币的邻近/接触检测触发；生成的币也有 Rapier 物理体。用图鉴查看条件，关注环境倍率与最近联动提示。特殊币外圈蓝环表示充能、内圈粉环表示倍率印记，普通币用染色提示。
4. 每个关间商店可免费领一份代币包，也可用贝壳购买各一份；补给与永久升级共享贝壳钱包。免费领取 / 购买状态都保存，刷新不能重复领取。
5. 进入下一关保留台面、币仓、强化币值及杀手币使用次数，自动补充 1 枚杀手币。

| 构筑 | 代币 | 联动 |
| --- | --- | --- |
| 种植 | 种子 / 水滴 / 摇钱树 | 种子接水消耗水并成长；树每 8 秒生成金币，每关上限 6 枚；树不直接出售 |
| 捕食 | 虾米 / 鱼鱼 / 猫猫 / 鼠鼠 | 鱼吃虾加币值，猫吃鱼鼠加币值与贝壳；鱼入账生成两枚水滴，可转回种植路线 |
| 孵化 | 母鸡 / 蛋蛋 / 公鸡 | 母鸡跨关产两枚蛋，蛋跨关变母鸡，公鸡每关可额外唤醒每只母鸡一次 |
| 增幅 | 幸运草 / 倍率 / 回响 | 草提供台面环境倍率；倍率印记每枚目标最多一次；回响复制前一个特殊好币 |
| 充能 | 闪电 / 蓄电池 | 闪电充能，水滴能传导，电池可吸走充能换自身币值；有次数上限，不无限自循环 |
| 物理 | 磁铁 / 爆破 | 磁铁聚拢附近好币；爆破入账时施加向前沿的物理冲量，可引爆附近爆破币 |
| 成长 | 遗迹 | 留在台面每跨一关基础币值 +20，上限 +140 |
| 净化 | 杀手 | 优先清 2.3 范围内坏币，每枚 +1 贝壳，累计 6 次后消耗 |

### 坏币压力与边界

第 1 关无自动坏币。第 2 关起每关开场投入 1～4 枚；之后每 12 次手动投币再投入一枚，台面坏币上限 8 枚。

- **锈蚀坏币**：在台面时环境倍率 -10%，最多 3 枚；入账扣 40 分。
- **盗壳坏币**：每 6 秒偷 1 贝壳，每关最多 3 次；入账扣 60 分。
- **腐蚀坏币**：每 6 秒可吞附近普通币，每关最多 3 枚；入账扣 80 分。
- 坏币扣分最低到 0，不触发连击、FEVER 或奖励。净化优先于同一轮坏币行动。
- 好币分数 = 强化后的币值 × 构筑倍率 × 连击 × FEVER × 环境倍率。强化币值包含永久倍率印记、充能与币值成长。
- 台面总上限 420 枚，爆破连锁最多 16 次；产蛋、树、捕食、充能均设有限次触发，避免无限繁殖或刷分死循环。
- 存档升级为 version 3，继续沿用原存档键，兼容 version 2：保留旧关卡与台面并发放初始币仓，下一次跨关启用坏币压力。回退旧版程序不保证读取新版存档。

**平衡说明：这是首版机制与交互，不是原作 150 种代币、全部镀层/道具/角色系统的完整复刻。自动化验证不等于真人八关无辅助平衡测试。**

规则参考：[Steam 官方公开介绍](https://store.steampowered.com/app/3784030/RACCOIN_Coin_Pusher_Roguelike/) 与 [PC Gamer 代币机制列表](https://www.pcgamer.com/games/roguelike/raccoin-special-coins-list)。只参考玩法概念，未采用其图片、音效或代码；本作规则和数值以币仓图鉴为准。

## v2 玩法

- 共 8 关，目标分依次为 **300 / 650 / 1100 / 1750 / 2600 / 3700 / 5100 / 6800**。
- 每关基础 **50 次投币**，额度不跨关累计。赢币只得分，不返还投币次数。v3 起可用入账票兑换额外次数，每关最多 2 次。
- 达标后可点击“结算本关”，也可以继续投币争取超额奖励。
- 最后一枚投出后，保留 **15 秒落币结算**；尚有老虎机或金币雨奖励时，倒计时至少保留 3 秒，避免截断未完成奖励。
- 达标进入商店，第 8 关达标则胜利；用尽额度且结算后仍未达标，本局结束。
- 下一关**保留台面、待落金币雨、老虎机及保留次数**；清除 FEVER / 临时护墙 / 超级推板，再应用本局的永久升级与开局护墙。
- 商店、玩法说明和切到后台时暂停游戏。购买记录、结算状态、物理台面与抽奖进度自动保存，刷新不会重复发放通关奖励。

### 计分

```text
本次得分 = round(基础分 × 构筑倍率 × 连击倍率 × FEVER倍率)
```

| 币种 | 基础分 |
| --- | ---: |
| 普通金币 | 10（可升级） |
| 大金币 | 100 |
| 宝石 | 200 |
| 大肥鱼立牌 | 300 |

基础构筑倍率为 ×1.00；“倍率芯片”每级 +0.25。0.7 秒内连续进币时，连击每次增加 ×0.1，最高 ×1.5。4 秒内累计赢 9 枚触发 FEVER，基础持续 12 秒，期间得分 ×2。倍率按每次入账时计算，四舍五入至整数。

### 贝壳与商店

贝壳与投币次数是两个独立资源。通关奖励为 `8 + 当前关卡 × 2` 贝壳；每剩 5 次投币额外 +1（最多 +6），每超出目标分的 25% 额外 +1（最多 +4）。贝壳保留到本局结束。

每次展示 3 件随机商品，第一间商店保证出现倍率芯片；每件每个货架限购一次。可花 3 贝壳刷新一次，不回退已生效的购买；满级升级不再出现。

| 商品 | 效果 | 等级上限 | 起价 / 每级涨价 |
| --- | --- | ---: | ---: |
| 倍率芯片 | 基础倍率 +0.25 | 8 | 8 / +4 |
| 金币抛光 | 普通金币基础分 +2 | 8 | 8 / +4 |
| 扩容币仓 | 之后每关投币额度 +8 | 5 | 10 / +5 |
| 推板改装 | 永久推进行程 +0.12 | 5 | 10 / +5 |
| 开局护墙 | 每关开局护墙 +6 秒 | 5 | 8 / +4 |
| 幸运门扩展 | LUCKY 门有效宽度 +0.20 | 4 | 10 / +5 |
| 狂热电池 | FEVER 时长 +3 秒 | 4 | 8 / +4 |
| 应急币袋 | 仅下一关 +12 次投币 | 一次性 | 5 |
| 松台销 | 每投入 20 枚自动摇台一次；与推板改装叠加后摇动更有力 | 1 | 8 / +0 |
| 币槽扩容 | 特殊币槽 +1，最多 4 格 | 2 | 8 / +4 |

当前是肉鸽基础循环版本，**现已加入首批特殊代币联动与坏币；尚无多角色、镀层与成就**。关卡曲线为初版参数，仍需更多真人游玩验证长期平衡性。

## 操作与存档

- **左槽**：Q、鼠标左键，或屏幕「左槽」。硬币向右滑；推板前进时留在左侧，收回时滑到中间。
- **右槽**：E、鼠标右键，或屏幕「右槽」。方向相反。
- **中槽**：W、空格、鼠标中键，或屏幕「中槽」。直接落在中间。
- 按住约半秒锁定连投，再点一下解除。连续点按比按住更快。触屏请用三个槽按钮，点玻璃只用于摸大肥鱼。
- R 键轮换已装填的币。特殊币装进币槽后，从正在摆动的中间滑槽落下，落点跟摆槽当时的位置走。
- 能量条满 8 次入账就转盘。过关先看航路三选一。补给站、币仓和说明可以收成小标签。
- 「兑币」用入账票换投币次数；「摇台」每局一次。
- 绿色 `LUCKY` 门触发老虎机；大奖金币雨及奖品继续通过物理场景得分。
- 右上角按钮控制音效、音乐、玩法说明与本局重置。手机设置在冠牌齿轮里。
- 本地存档键为 `raccoon-pusher-run-v2`。旧版 `raccoon-pusher-save-v1` 保留，但不会自动转换为关卡存档；重置新模式不会删除旧版存档。
- 存档仅属于当前浏览器和设备。浏览器禁用或清除本地存储后无法恢复。

```sh
npm ci

npm run build
```

根目录 `index.html` 使用固定版本 CDN 导入映射，需联网。修改界面模板后运行：
