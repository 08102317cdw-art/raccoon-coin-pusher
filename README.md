# 大肥鱼推币机 · Dafeiyu Coin Pusher

Three.js + Rapier 制作的开源 3D 推币机。**v2 加入八关肉鸽循环：限量投币 → 目标分 → 结算 → 商店构筑 → 下一关。** 保留物理推币、LUCKY 门、老虎机、FEVER、大肥鱼互动立牌和程序化音效。

[🎮 在线试玩](https://08102317cdw-art.github.io/raccoon-coin-pusher/)

这是独立的免费非商业同人游戏，不是 Steam《RACCOIN》的移植，也不是 DeepSeek 官方作品，未获官方背书。未使用 RACCOIN 的美术、音频或代码。

## v2.4 一屏海湾机台

- **手机就是机台**：冠牌、计分 LED、抽奖屏、3D 推币窗和实体投币台连为一体，不再用上下两条应用工具栏夹着一台小机器。
- **真正放大的抽奖屏**：把同一张实时转轮画布安装进手机背板，抽奖结果、听牌、保留次数和实际奖励使用同一个状态；不是预制视频或装饰图片。
- **制造细节**：海纹珐琅背板、黄铜镶线、微纹理、嵌入扬声器、导轨螺钉、镀铬边框与鲸鱼徽章；统一抽奖屏和机身的海湾视觉语言。
- **拇指操作**：币舱装填槽、椭圆投币键和资源显示都放在操作台上；右上角设置舱收纳音效、音乐、说明和重置。打开设置时暂停物理和投币。
- **海湾环境**：海边游乐厅顶棚、串灯、灯塔、帆船、海鸟与木栈道覆盖原有黑色背景。环境是一张按视口缓存的纹理，静态机身细节按材质合批，控制手机渲染开销。
- **旋转与小屏**：针对手机浏览器动态高度、小屏竖屏和横屏重新排布。跨越桌面断点时归还原有控件和实时画布，不重开游戏。
- 八关规则、特殊币联动、经济与存档格式不变。`npm run pages` 生成线上入口；`npm run build` 生成包含样式和美术绘图的离线 HTML。

## v2.2 特殊代币联动

首批 **19 种特殊代币 + 3 种坏币**。这是参考公开玩法后独立实现、重新平衡的大肥鱼版，不宣称与 RACCOIN 逐项一致。

### 怎么玩

1. 点击 HUD 的「普通金币 ∞ · 选择」打开币仓，选择下一种投币；桌面可按 **Q** 轮换有库存的币。
2. 特殊币替换普通投币，**仍消耗一次关卡投币额度**，另消耗一枚币仓库存；用完自动回到普通币。新局附带首批组合试用币。
3. 联动由真实台面代币的邻近/接触检测触发；生成的币也有 Rapier 物理体。用图鉴查看条件，关注环境倍率与最近联动提示。特殊币外圈蓝环表示充能、内圈粉环表示倍率印记，普通币用染色提示。
4. 每个关间商店可免费领一份代币包，也可用贝壳购买各一份；补给与永久升级共享贝壳钱包。免费领取 / 购买状态都保存，刷新不能重复领取。
5. 进入下一关保留台面、币仓、强化币值及杀手币使用次数，自动补充 1 枚杀手币。

| 构筑 | 代币 | 联动 |
| --- | --- | --- |
| 种植 | 种子 / 水滴 / 摇钱树 | 种子接水消耗水并成长；树每 8 秒生成金币，每关上限 6 枚；树不直接出售 |
| 捕食 | 虾米 / 鱼鱼 / 猫猫 / 鼠鼠 | 鱼吃虾加币值，猫吃鱼鼠加币值与贝壳；鱼入账生成两枚水滴，可转回种植路线 |
| 孵化 | 母鸡 / 蛋蛋 / 公鸡 | 母鸡跨关产两枚蛋，蛋跨关变母鸡，公鸡每关可额外唤醒每只母鸡一次 |
| 增幅 | 幸运草 / 倍率 / 回响 | 草提供台面环境倍率；倍率印记每枚目标最多一次；回响复制前一个特殊好币 |
| 充能 | 闪电 / 蓄电池 | 闪电充能，水滴能传导，电池可吸走充能换自身币值；有次数上限，不无限自循环 |
| 物理 | 磁铁 / 爆破 | 磁铁聚拢附近好币；爆破入账时施加向前沿的物理冲量，可引爆附近爆破币 |
| 成长 | 遗迹 | 留在台面每跨一关基础币值 +20，上限 +140 |
| 净化 | 杀手 | 优先清 2.3 范围内坏币，每枚 +1 贝壳，累计 6 次后消耗 |

### 坏币压力与边界

第 1 关无自动坏币。第 2 关起每关开场投入 1～4 枚；之后每 12 次手动投币再投入一枚，台面坏币上限 8 枚。

- **锈蚀坏币**：在台面时环境倍率 -10%，最多 3 枚；入账扣 40 分。
- **盗壳坏币**：每 6 秒偷 1 贝壳，每关最多 3 次；入账扣 60 分。
- **腐蚀坏币**：每 6 秒可吞附近普通币，每关最多 3 枚；入账扣 80 分。
- 坏币扣分最低到 0，不触发连击、FEVER 或奖励。净化优先于同一轮坏币行动。
- 好币分数 = 强化后的币值 × 构筑倍率 × 连击 × FEVER × 环境倍率。强化币值包含永久倍率印记、充能与币值成长。
- 台面总上限 420 枚，爆破连锁最多 16 次；产蛋、树、捕食、充能均设有限次触发，避免无限繁殖或刷分死循环。
- 存档升级为 version 3，继续沿用原存档键，兼容 version 2：保留旧关卡与台面并发放初始币仓，下一次跨关启用坏币压力。回退旧版程序不保证读取新版存档。

**平衡说明：这是首版机制与交互，不是原作 150 种代币、全部镀层/道具/角色系统的完整复刻。自动化验证不等于真人八关无辅助平衡测试。**

规则参考：[Steam 官方公开介绍](https://store.steampowered.com/app/3784030/RACCOIN_Coin_Pusher_Roguelike/) 与 [PC Gamer 代币机制列表](https://www.pcgamer.com/games/roguelike/raccoin-special-coins-list)。只参考玩法概念，未采用其图片、音效或代码；本作规则和数值以币仓图鉴为准。

## v2 玩法

- 共 8 关，目标分依次为 **300 / 650 / 1100 / 1750 / 2600 / 3700 / 5100 / 6800**。
- 每关基础 **50 次投币**，额度不跨关累计。赢币只得分，不返还投币次数；移除了旧版免费补币和经验奖励。
- 达标后可点击“结算本关”，也可以继续投币争取超额奖励。
- 最后一枚投出后，保留 **15 秒落币结算**；尚有老虎机或金币雨奖励时，倒计时至少保留 3 秒，避免截断未完成奖励。
- 达标进入商店，第 8 关达标则胜利；用尽额度且结算后仍未达标，本局结束。
- 下一关**保留台面、待落金币雨、老虎机及保留次数**；清除 FEVER / 临时护墙 / 超级推板，再应用本局的永久升级与开局护墙。
- 商店、玩法说明和切到后台时暂停游戏。购买记录、结算状态、物理台面与抽奖进度自动保存，刷新不会重复发放通关奖励。

### 计分

```text
本次得分 = round(基础分 × 构筑倍率 × 连击倍率 × FEVER倍率)
```

| 币种 | 基础分 |
| --- | ---: |
| 普通金币 | 10（可升级） |
| 大金币 | 100 |
| 宝石 | 200 |
| 大肥鱼立牌 | 300 |

基础构筑倍率为 ×1.00；“倍率芯片”每级 +0.25。0.7 秒内连续进币时，连击每次增加 ×0.1，最高 ×1.5。4 秒内累计赢 9 枚触发 FEVER，基础持续 12 秒，期间得分 ×2。倍率按每次入账时计算，四舍五入至整数。

### 贝壳与商店

贝壳与投币次数是两个独立资源。通关奖励为 `8 + 当前关卡 × 2` 贝壳；每剩 5 次投币额外 +1（最多 +6），每超出目标分的 25% 额外 +1（最多 +4）。贝壳保留到本局结束。

每次展示 3 件随机商品，第一间商店保证出现倍率芯片；每件每个货架限购一次。可花 3 贝壳刷新一次，不回退已生效的购买；满级升级不再出现。

| 商品 | 效果 | 等级上限 | 起价 / 每级涨价 |
| --- | --- | ---: | ---: |
| 倍率芯片 | 基础倍率 +0.25 | 8 | 8 / +4 |
| 金币抛光 | 普通金币基础分 +2 | 8 | 8 / +4 |
| 扩容币仓 | 之后每关投币额度 +8 | 5 | 10 / +5 |
| 推板改装 | 永久推进行程 +0.12 | 5 | 10 / +5 |
| 开局护墙 | 每关开局护墙 +6 秒 | 5 | 8 / +4 |
| 幸运门扩展 | LUCKY 门有效宽度 +0.20 | 4 | 10 / +5 |
| 狂热电池 | FEVER 时长 +3 秒 | 4 | 8 / +4 |
| 应急币袋 | 仅下一关 +12 次投币 | 一次性 | 5 |

当前是肉鸽基础循环版本，**现已加入首批特殊代币联动与坏币；尚无多角色、镀层与成就**。关卡曲线为初版参数，仍需更多真人游玩验证长期平衡性。

## 界面与镜头（v2.0.1）

- 桌面端使用独立右侧操作栏，目标分、投币额度、贝壳、设置与结算均不覆盖 3D 画面。
- 手机端分为顶部紧凑状态栏、中央游戏视口与底部操作区；达标按钮出现时自动预留空间。

- 镜头按游戏视口和机台真实区域自动取景，保留招牌、老虎机、推板与出币前沿；投币瞄准及浮动文字同步使用新视口坐标。

## 操作与存档

- 移动鼠标 / 触屏拖动：瞄准顶部投币器。
- 点击、长按或空格：投币；手机可点“投币”按钮，A/D 或左右方向键也能调整投币位置。
- 绿色 `LUCKY` 门触发老虎机；大奖金币雨及奖品继续通过物理场景得分。
- 右上角按钮控制音效、音乐、玩法说明与本局重置。
- 本地存档键为 `raccoon-pusher-run-v2`。旧版 `raccoon-pusher-save-v1` 保留，但不会自动转换为关卡存档；重置新模式不会删除旧版存档。
- 存档仅属于当前浏览器和设备。浏览器禁用或清除本地存储后无法恢复。

## 本地构建

需要 Node.js 18+。

```sh
npm ci
npm test
npm run build
```

打开 `dist/raccoon-coin-pusher.html` 即可离线游玩；依赖已内联，不需要本地服务。

### GitHub Pages

根目录 `index.html` 使用固定版本 CDN 导入映射，需联网。修改界面模板后运行：

```sh
npm run pages
```

然后提交 `index.html` 与 `src/`。仓库 Pages 设置为 `main` 分支、`/(root)`；推送后 GitHub 自动重新发布。不需要 Actions 工作流权限。

### 测试

```sh
npm test                         # 无浏览器的纯规则断言
CHROMIUM_PATH=/path/to/chromium node tests/browser.cjs
CHROMIUM_PATH=/path/to/chromium node tests/layout.cjs
CHROMIUM_PATH=/path/to/chromium node tests/theme.cjs
node tests/tokens.test.cjs
CHROMIUM_PATH=/path/to/chromium node tests/token-browser.cjs
```

浏览器集成测试需要安装 Chromium；覆盖投币输入、物理落币得分、购买、保存恢复、失败重开、八关状态迁移以及 390px 手机界面。用可控物理奖品事件验证全部关卡，不代表已经通过真人无辅助通关或完成平衡性验证。
